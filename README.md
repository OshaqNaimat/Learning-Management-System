# 🎓 Learning Management System



A complete web-based **Learning Management System (LMS)** built with Laravel to help educational institutions manage students, teachers, classes, courses, assignments, and academic activities through a centralized platform.



## 🚀 Features


**Admin Portal**
![Admin Dashboard](public/teacher.png)

### 👨‍💼 Admin Panel



- Centralized admin dashboard

- Student management

- Teacher management

- Class and course management

- Academic records management

- User and role management

- Attendance management

- Assignment management

- Examination and result management

- Administrative reports



### 👨‍🏫 Teacher Portal



- Teacher dashboard

- Manage assigned classes

- Manage students

- Create and manage assignments

- Track student attendance

- Manage academic activities

- View class information



### 👨‍🎓 Student Portal



- Student dashboard

- View enrolled classes and courses

- View assignments

- Track attendance

- View academic information

- Access learning-related activities

## 🔐 Authentication & Roles



The system provides role-based access so different users can access the features relevant to their role.



Supported roles include:



- 👨‍💼 Admin

- 👨‍🏫 Teacher

- 👨‍🎓 Student
